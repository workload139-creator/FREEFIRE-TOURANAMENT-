Admin panel ka use — yahin se website manage karein

Kaam ka sahi order: Tournament banayein → payment proof/UTR check karein → entry confirm karein → match/room details manage karein → kill evidence ka AI report dekhein → khud final approve/reject karein → actual prize transfer ke baad payout reference darj karein.

Important: AI sirf initial suggestion deta hai. Winner ya kills ka final decision admin karega. Payment ko tabhi verified karein jab bank/UPI statement mein paisa sach mein mila ho. Website payout mark karne se pehle real UPI transfer karein.

⚡ Quick Actions — direct yahan click karein

🏆 1. Tournament banana aur manage karna

BR/VS mode, VS format (1v1–4v4), entry fee, prize pool, start time aur Upcoming status set karein.

Tournament list / Add tournament

💳 2. Registration payment verify karna

Player ka UTR aur actual bank/UPI receipt match karein. Registration select karke action menu se Verify UTR against actual UPI/bank receipt and confirm entry chalayein.

Registrations & payment review

🎮 3. Kill proof + AI report + final admin decision

Submission kholein; video, dono history screenshots, registered UID, AI proposed kills/confidence/notes dekhein. Phir final kills/reward aur admin notes review karein. AI suggestion ko bina evidence check kiye approve na karein.

Open Kill Verification queue

🥇 4. Winner prize / BR kill prize payout

Tournament mein winner UID aur prize pool check karein. BR kill prize ke liye Kill Verification queue mein approved submission, approved reward aur payout reference use karein. UPI app se actual transfer ke baad hi real UTR/reference enter karke Paid action chalayein.

Winner prize settings BR kill prize payout

👥 5. Players / profiles

Username, email, phone, Free Fire UID aur player account status manage karein.

Player accounts

💰 6. Wallet, deposit aur withdrawal requests

Player deposit ko actual payment check ke baad approve karein. Withdrawal ko actual UPI transfer ke baad payout reference ke saath Paid mark karein. Wallet ledger ko manually edit na karein.

Tournament list mein tournament select karke cancel/refund action use karein. Manual UPI refund ke liye pehle real transfer karein, phir registration mein unique refund UTR daal kar refund action chalayein.
