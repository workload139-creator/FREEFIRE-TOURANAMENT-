FF Tournament — Admin Control Room

Yahin se kaam shuru karein. Neeche har kaam ka alag button aur step diya hai. Pehle tournament banayein, phir registration/payment verify karein, match chalayein, aur end mein result/prize complete karein.

1. 🏆 Tournament banana

Naya match/room banane ke liye. BR ya VS mode, 1v1–4v4 format, entry fee, prize, player limit aur start time bharein. Website par dikhane ke liye status Upcoming rakhein.

+ Create Tournament

2. 📋 Sabhi tournaments

Banaye hue matches dekhein/edit karein. Match shuru karne ke liye tournament kholein aur status ko Live karein. Match khatam hone par status Completed karein.

Manage Tournaments

3. 👥 Player registration

Har player ka naam, profile ID, Free Fire UID, contact, UPI/QR aur registration status dekhein. Kisi player ki poori detail ke liye uski row/ID par click karein.

Player Registrations

4. 💳 Entry payment verify

Registration open karein, UTR note karein aur apne UPI/bank statement mein asal payment check karein. Phir list par wapas aakar checkbox select karein → Action → Verify UTR against actual UPI/bank receipt and confirm entry → Go.

Verify Payments

5. 🎮 Room ID / Password

Tournament edit karein, Room Details mein Room ID aur password bharein. Sirf eligible paid players ko share karein; phir registration list mein room/ready status dekhein.

Room & Match Setup

6. 🎥 Kill proof + AI review

Player ki video aur dono screenshots kholein. Registered UID se match karein. AI result sirf suggestion hai; approved kills/reward aur final status aapko evidence dekhkar set karna hai.

Review Kill Evidence

7. 🥇 Winner & prize

Tournament edit karein, Winner UID bharein, matching verified player aur prize pool check karein. Actual UPI transfer ke baad real unique UTR enter karein; phir tournament list mein select karke winner prize action chalayein.

Winner / Prize

8. 💸 Kill reward payout

Kill submission kholein, final kills/reward approve karein. Asal UPI transfer karne ke baad payout reference bharein; list par action se Paid record karein.

Kill Reward Payout

9. ↩️ Cancel / refund

Sirf cancellation confirm hone par tournament list select karein → Action → Cancel tournament and refund registered players. Manual UPI refund ka record karne se pehle asal transfer aur unique UTR verify karein.

Cancel / Refund
Important: Website abhi payment ko apne aap UPI se transfer nahi karti. Payment/Prize/Refund ko tabhi verified ya paid mark karein jab bank/UPI app mein transaction sach mein dikh raha ho. AI bhi final judge nahi hai. Tournament start karna ho to Manage Tournaments → tournament title → Schedule & Status → Status = Live → Save.
